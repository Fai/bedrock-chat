## Success Strategies for 2-Month Plan

### **Efficiency Tips:**
1. **Skip what you know:** You have SAA - skip basic VPC/IAM if solid
2. **Focus on security-specific services:** GuardDuty, Macie, Inspector, Security Hub
3. **Speed up videos:** Watch courses at 1.25-1.5x speed
4. **Batch similar topics:** Do all encryption labs together
5. **Use weekends strategically:** Longer labs that need concentration

### **What to Prioritize:**
**High Priority (60% of time):**
- IAM advanced scenarios (permission boundaries, SCPs, session policies)
- KMS (key policies, grants, rotation, encryption patterns)
- GuardDuty, Security Hub, Detective (finding types, automation)
- VPC security (endpoints, NACLs, Flow Logs)
- CloudTrail + CloudWatch (logging, monitoring, alerts)

**Medium Priority (30% of time):**
- WAF, Shield, Network Firewall
- Config, EventBridge automation
- Inspector, Macie
- Secrets Manager, ACM
- Organizations, Control Tower

**Lower Priority (10% of time):**
- CloudHSM (know differences from KMS)
- Directory Service (basic understanding)
- Audit Manager, Artifact
- Advanced networking (Transit Gateway, Direct Connect)

### **What You Can Skim (Due to SAA Background):**
- Basic VPC concepts (subnets, routing, IGW)
- Basic IAM (users, groups, policies)
- S3 bucket policies (unless encryption-specific)
- Basic EC2 security groups
- CloudFormation security (unless compliance-related)
